# Rishit Das — Portfolio

Single-file static site. No build step needed.

**Live:** [https://rishit-das-portfolio.vercel.app](https://rishit-das-portfolio.vercel.app)

## Edit

Everything lives in `index.html` — project cards, about text, and stack list are plain HTML/CSS. Open it in any editor and change what you need.

## Deploy

Already deployed on Vercel. To re-deploy after edits:

1. Push changes to this repo
2. Or drag `index.html` into the Vercel dashboard
